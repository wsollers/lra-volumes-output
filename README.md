Published PDF Outputs for Learning Real Analysis
================================================

This repository is maintained by GitHub Actions from the `lra-volume-*`
repositories.

PDFs are published under edition directories:

- `digital/*.pdf`
- `print/*.pdf`
- `reference/*.pdf`

GitHub Pages serves those paths so the Knowledge Explorer can open a volume PDF
directly in a browser window.

The Pages root also serves `index.html`, a lightweight download page styled to
match the Knowledge Explorer and populated from the repository's published PDF
directories.
